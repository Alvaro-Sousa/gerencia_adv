## Objetivo da estrutura

Organizar o projeto de forma que cada parte fique separada por responsabilidade, facilitando manutenção e crescimento futuro.

## Organização por app

- `accounts`: autenticação, cadastro e perfis
- `processes`: tipos de processos e solicitações
- `documents`: upload e controle de documentos
- `dashboard`: telas principais e acompanhamento

## Observação

A estrutura pode ser refinada conforme o projeto for evoluindo, mas essa base já é suficiente para começar a desenvolver no VS Code.
