# Gerencia Adv

Sistema de gestão jurídica para advogado individual, com foco em organizar solicitações de processos, documentos necessários e acompanhamento de status por cliente e advogado.

## Sobre o projeto

O objetivo do Gerencia Adv é centralizar o fluxo de atendimento jurídico em uma única plataforma, facilitando a comunicação entre cliente e advogado e reduzindo retrabalho com envio de documentos e atualização de andamento.

## Problema que o projeto resolve

Muitos atendimentos jurídicos acabam espalhados entre mensagens, e-mails e documentos soltos. Isso dificulta o controle do que já foi enviado, do que ainda falta e de como cada processo está evoluindo.

Este sistema propõe reunir tudo isso em um único lugar.

## Perfis de usuário

### Cliente
- Criar conta
- Fazer login
- Visualizar tipos de processos
- Solicitar abertura de processo
- Enviar documentos obrigatórios
- Acompanhar status do processo
- Ver histórico de solicitações

### Advogado
- Criar conta profissional
- Fazer login
- Visualizar solicitações recebidas
- Analisar documentos enviados
- Atualizar status dos processos
- Consultar histórico
- Ver dados completos dos clientes

## Funcionalidades iniciais

- Cadastro e autenticação de usuários
- Controle de perfis de acesso
- Catálogo de tipos de processos
- Lista de documentos obrigatórios por processo
- Solicitação de processo pelo cliente
- Upload de documentos
- Atualização de status pelo advogado
- Histórico de mudanças de status
